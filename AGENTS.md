# Правила проекта

- Отвечайте кратко и по-русски. Разделяйте задачи по владению файлами и делегируйте реализацию подходящим агентам. Маршрутизация: `/Users/georgekornilov/.codex/references/subagent-model-and-reasoning.md`.
- Go: стандартная библиотека прежде всего, `context` и таймауты для внешних вызовов, обёрнутые ошибки, никакого изменяемого глобального состояния; `gofmt`, `go vet`, значимые тесты с `-race`.
- React: типизированные props и hooks, очистка эффектов и опроса, семантические доступные формы, секреты никогда не попадают в клиент; проверяйте typecheck и build.
- Тесты используют mock HTTP LLM/MCP, не расходуют деньги на реальные API. Фиксируйте версии зависимостей и lockfiles.
- Контракт HTTP и semantics scheduler описаны в `docs/api.md` и `SPEC.md`. Изменения контракта согласуйте с владельцем frontend и тестов.
